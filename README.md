# 프롬프트 관리 프로그램

파이썬으로 만든 콘솔 기반 프롬프트 관리 프로그램입니다.

사용자가 자주 사용하는 프롬프트를 저장하고, 목록 확인, 카테고리별 보기, 검색, 상세 보기, 즐겨찾기 기능을 사용할 수 있습니다.
텍스트 생성을 위한 지시문, 이미지 생성용 키워드, 페르소나 설계안 등의 여러가지 프롬프트를 깔끔하게 정리해 사용할 수 있습니다. 


## 주요 기능

- 새 프롬프트 추가
- 전체 프롬프트 목록 보기
- 카테고리별 프롬프트 보기
- 프롬프트 검색
- 프롬프트 상세 보기
- 즐겨찾기 추가 및 해제
- 즐겨찾기 목록 보기
- JSON 파일로 데이터 저장 및 불러오기

## 사용한 기술

- Python
- JSON
- 리스트와 딕셔너리
- 함수
- 반복문과 조건문
