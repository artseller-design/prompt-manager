# 프롬프트 관리 프로그램

파이썬으로 만든 콘솔 기반 프롬프트 관리 프로그램입니다.

사용자가 자주 사용하는 프롬프트를 등록하고, 목록 확인, 카테고리별 조회, 검색, 상세 보기, 즐겨찾기 관리 기능을 사용할 수 있습니다.  
텍스트 생성, 이미지 생성, 영상 생성, 페르소나 설계, 자동화 등 다양한 목적의 프롬프트를 체계적으로 관리하기 위해 제작했습니다.

---

## 1. 프로젝트 목적

AI 도구를 사용할 때 자주 쓰는 프롬프트를 매번 다시 작성하는 불편함을 줄이기 위해 이 프로그램을 만들었습니다.

이 프로그램을 사용하면 프롬프트를 제목, 내용, 카테고리, 즐겨찾기 여부와 함께 저장할 수 있으며, 필요한 프롬프트를 빠르게 검색하거나 카테고리별로 확인할 수 있습니다.

---

## 2. 주요 기능

### 1) 새 프롬프트 추가

사용자가 새로운 프롬프트를 등록할 수 있습니다.

입력 항목은 다음과 같습니다.

- 제목
- 내용
- 카테고리

프롬프트를 추가하면 기본적으로 즐겨찾기 값은 `False`로 저장됩니다.

---

### 2) 전체 프롬프트 목록 보기

저장된 모든 프롬프트를 번호와 함께 출력합니다.

출력 정보는 다음과 같습니다.

- 번호
- 제목
- 카테고리
- 즐겨찾기 여부

즐겨찾기된 프롬프트는 별표 표시로 확인할 수 있습니다.

---

### 3) 카테고리별 프롬프트 보기

등록된 프롬프트의 카테고리 목록을 보여주고, 사용자가 선택한 카테고리에 해당하는 프롬프트만 출력합니다.

사용 가능한 카테고리 예시는 다음과 같습니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

---

### 4) 프롬프트 검색

키워드를 입력하면 제목 또는 내용에 해당 키워드가 포함된 프롬프트를 검색합니다.

검색 결과가 있으면 목록으로 출력하고, 검색 결과가 없으면 안내 메시지를 출력합니다.

---

### 5) 프롬프트 상세 보기

프롬프트 번호를 입력하면 해당 프롬프트의 전체 내용을 확인할 수 있습니다.

출력 정보는 다음과 같습니다.

- 제목
- 카테고리
- 즐겨찾기 여부
- 프롬프트 내용

잘못된 번호를 입력하면 안내 메시지를 출력합니다.

---

### 6) 즐겨찾기 추가 및 해제

프롬프트 번호를 입력하여 즐겨찾기를 추가하거나 해제할 수 있습니다.

이미 즐겨찾기 상태인 경우 다시 선택하면 즐겨찾기가 해제됩니다.

---

### 7) 즐겨찾기 목록 보기

즐겨찾기된 프롬프트만 따로 모아서 확인할 수 있습니다.

즐겨찾기된 프롬프트가 없을 경우 안내 메시지를 출력합니다.

---

### 8) JSON 파일 저장 및 불러오기

프로그램에서 등록한 프롬프트 데이터는 JSON 파일로 저장됩니다.

프로그램을 종료했다가 다시 실행해도 이전에 저장된 프롬프트를 불러와 사용할 수 있습니다.

## 5. 프로그램 메뉴

프로그램을 실행하면 다음과 같은 메뉴가 출력됩니다.

```text
===== 프롬프트 관리 프로그램 =====
1. 새 프롬프트 추가
2. 전체 프롬프트 보기
3. 카테고리별 프롬프트 보기
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 추가/해제
7. 즐겨찾기 목록 보기
0. 프로그램 종료
메뉴 번호를 입력하세요:
```

사용자는 번호를 입력하여 원하는 기능을 선택할 수 있습니다.

---

## 6. 데이터 구조

프롬프트 데이터는 리스트 안에 딕셔너리를 저장하는 방식으로 관리합니다.

예시:

```python
prompts = [
    {
        "title": "블로그 글 작성 프롬프트",
        "content": "주어진 주제로 블로그 글을 작성해줘.",
        "category": "텍스트 생성",
        "favorite": False
    },
    {
        "title": "이미지 생성 프롬프트",
        "content": "미래 도시를 배경으로 한 이미지를 생성해줘.",
        "category": "이미지 생성",
        "favorite": True
    }
]
```

각 프롬프트는 다음 정보를 포함합니다.

| 항목 | 설명 |
|---|---|
| title | 프롬프트 제목 |
| content | 프롬프트 내용 |
| category | 프롬프트 카테고리 |
| favorite | 즐겨찾기 여부 |
